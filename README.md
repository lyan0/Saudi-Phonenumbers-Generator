
# Saudi Number Generator
A simple and customizable tool that generates random Saudi phone numbers.

## Features:
- Generate random Saudi phone numbers
- Easy to modify and customize
- Can be used for testing and development

## Purpose:
This project is a reusable template that can be modified and used in different projects.
